## Intent

**Problème :** aucun Parser n'est enregistré pour le format `pdf`. Un Corpus qui contient des PDF est donc refusé par `parser: auto` (`ConfigError` « pdf_text non encore disponible »), et une Question ne peut pas citer une page.

**Approche :** ajouter le Parser `pdf_text` (pypdfium2). Il produit un Ancrage `<doc_id>#p<page>` par page, avec des pages numérotées à partir de 1, et un Block `text` par page non vide. Il est enregistré au `kind` `parser` avec `formats = {"pdf"}`, si bien que `ingest`, le cache de parsing et `ParsedCorpus.resolve` existants le prennent en charge sans modification.

## Boundaries & Constraints

**Toujours :** `doc_id = sha16_bytes(raw)` ; une entrée de `anchors` par page, dans l'ordre, avec `page` renseigné, `heading_path=()` et `source_path` du Document ; `format="pdf"` ; une erreur de lecture pypdfium2 est convertie en `ValueError` (message en français, avec `source_path`), car `ingest` n'intercepte que `OSError`/`ValueError` ; le document et les pages pdfium sont fermés (`close()` ou `with`), même en cas d'erreur ; l'attribut de classe `version = "1"` est présent ; les PDF de test sont générés dans le test par fpdf2 (police intégrée Helvetica, texte ASCII), sans fichier commité ni réseau.

**Jamais :** pas d'OCR, de docling, de détection de titres ni de tableaux dans un PDF ; aucune modification de `core/types.py`, `corpus/ingest.py`, `cli.py` ni `pyproject.toml` (pypdfium2 et fpdf2 y figurent déjà) ; `corpus` n'importe pas `components` (AD-1).

## Design Notes

- L'exigence « Ancrage existe avec un texte vide » est satisfaite par l'entrée d'`anchors` : `anchor_text` concatène les Blocks de l'ancrage et renvoie donc `""` quand il n'y en a pas. On n'émet pas de Block vide, conformément à la convention de 2.2 (des textes de Block jamais vides), et les Découpeurs n'ont pas à filtrer.
- Un seul Block par page, et non un par paragraphe : l'extraction pypdfium2 ne donne pas de structure de paragraphe fiable, et la page est l'unité d'Ancrage.

```python
try:
    pdf = pdfium.PdfDocument(raw)
except pdfium.PdfiumError as exc:
    raise ValueError(f"PDF illisible : {source_path} ({exc})") from exc
```

## Décisions prises sans l'utilisateur

- Une page sans texte donne un Ancrage sans Block (`anchor_text` = `""`) ; option écartée : un Block `text` vide.
- Un Block `text` par page ; option écartée : un Block par paragraphe ou par ligne.
- `PdfiumError` est convertie en `ValueError` dans le Parser ; option écartée : élargir l'interception d'exceptions dans `ingest.py`.
- Les PDF de test sont générés à la volée par fpdf2 avec Helvetica et du texte ASCII ; option écartée : police TTF commitée (elle relève de la story 2.5, Mini-corpus).
- Le test « non encore disponible » de 2.2 est mis à jour dans cette story ; option écartée : le laisser casser ou le supprimer.
- Pas d'extraction de titres, de tableaux ni d'images dans un PDF ; option écartée : heuristiques de structure (hors périmètre, docling est en extra).
