## Intent

**Problem:** Le comparatif n'a aucune Architecture à résumés hiérarchiques. On ne peut donc pas mesurer si un arbre de résumés aide les questions globales et multi-sauts (FR-23).

**Approach:** Ajouter l'Architecture `raptor`, sous-classe de `NaiveRag`. À l'indexation, elle construit un arbre par regroupement récursif et déterministe des embeddings, résume chaque groupe par le rôle `summarize`, puis indexe en dense l'arbre aplati (feuilles et nœuds). La requête et les Citations passent par la chaîne existante (`dense`, `labeled`, `llm`). Pas de mise à jour incrémentale : l'arbre est reconstruit au poste `update`.

## Boundaries & Constraints

**Always:**
- Le nœud de niveau n est un `Passage` avec `level = n` (≥ 1) et `child_ids` = ids des enfants, triés. Son `anchor_ids` est l'union ordonnée et dédoublonnée des Ancrages de ses feuilles. `doc_id` est celui du Document commun à toutes les feuilles, `None` si elles couvrent plusieurs Documents. `passage_id = sha16("node", "raptor", str(level), *sorted(child_ids))`.
- Les défauts sont `group_min = 5`, `group_max = 10`, `max_depth = 3`, `k = 5`. `query_params = {"k"}`. `capabilities = ArchCapabilities(incremental_update=False, retrieval_method="ranked")`.
- Appels `summarize` : step `raptor.summarize.level<n>`, `inputs={"text": ...}`, `seed=ctx.seed`. Le poste (`indexing` ou `update`) est fixé par le runner, jamais par l'Architecture. L'Architecture ne trace rien.
- Le résultat est déterministe : les enfants sont triés par `passage_id`, et à similarité égale on départage par id (AD-20).
- Toute Citation passe par la table `labels` de `labeled` : citer un nœud donne les Ancrages de ses feuilles (AD-7).

**Never:**
- Modifier `scoring/`, le runner, le Rapport, `roles.py` ou `fake.py` : le rôle `summarize` existe déjà.
- Ajouter une dépendance (UMAP, GMM, scikit-learn).
- Appeler le réseau ou un LLM réel. Lire `.env`.
- Laisser un index scénarisé dans `WL_HOME/index/` : les tests isolent `wl_home` dans `tmp_path`.

## Design Notes

L'algorithme de regroupement d'un niveau est glouton et déterministe. RAPTOR d'origine utilise UMAP et GMM, écartés ici pour éviter une dépendance de plus et le non-déterminisme :

```
restants = nœuds du niveau triés par passage_id
tant que restants :
    graine = restants[0]
    voisins = autres restants triés par (-cos(graine, v), passage_id)
    groupe = [graine] + voisins[:group_max - 1]   # groupes pleins ; seul le dernier peut être < group_min
    retirer groupe de restants
```

Les vecteurs d'un niveau servent à deux usages : le regroupement, et le store via `_encoder`, avec un seul `embed_passages` par lot. La boucle des niveaux s'arrête quand `level == max_depth` ou quand le niveau courant compte au plus un nœud. Un niveau d'au plus `group_max` nœuds donne une racine unique. Le texte envoyé à `summarize` est fait des textes des enfants, triés par id et joints par `"\n\n"`.

## Décisions prises sans l'utilisateur

- Regroupement glouton par similarité cosinus, avec une graine prise dans l'ordre des ids et des groupes pleins de `group_max`. Option écartée : UMAP + GMM ou k-means (dépendance, non-déterminisme).
- `Raptor` hérite de `NaiveRag`. Option écartée : une classe autonome (elle dupliquerait le store et la réponse).
- Modèle de résumé : `summarize_model` (ModelRef) qui retombe sur `generator_models[0]` du profil. Option écartée : un modèle figé ou un nouveau défaut de profil.
- `summary_max_tokens = 256` dans les Params, donc dans la clé d'index. Option écartée : le mettre dans `query_params`, alors qu'il change l'index.
- Retriever autre que `dense` refusé à la construction, comme `hyde`. Option écartée : accepter `hybrid` ou `lexical` sans index lexical.
- Résumé vide : repli sur la concaténation des enfants, avec un avertissement journalisé. Option écartée : l'échec de toute l'indexation.
- Nœud couvrant un seul Document : `doc_id` de ce Document. Option écartée : `None` systématique.
- Corpus à une seule feuille : aucun nœud de résumé. Option écartée : un nœud racine à un enfant.
- Configuration `raptor` dans `experiments/mini-test.yaml`, conformité et SM-3 reportées : ces fichiers sont absents du dépôt (story 4.14), comme pour les 6.x. Option écartée : les créer hors périmètre.
