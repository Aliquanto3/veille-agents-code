# Story 7.15 : Lancement de la Chaîne et bouton de mode

En tant que Pilote, je veux lancer la Chaîne et suivre ses 10 étapes dans le navigateur, et basculer en Mode repli d'un clic, pour montrer le rapport fait en une commande et préparer la démo hors réseau.

Critères d'acceptation de la story (extraits d'epics.md) :
- Given l'écran `/chaine`, when le Pilote clique sur le bouton de lancement, then le serveur démarre `usine rapport` en sous-processus (une Chaîne à la fois), et la page sonde chaque seconde l'état de la Chaîne.
- Given une Chaîne en cours, when le Pilote quitte puis rouvre `/chaine`, then le suivi reprend ; le bouton de lancement et le bouton de mode restent `aria-disabled="true"`, avec leur motif lié par `aria-describedby`.
- Given une étape en échec, when la CLI se termine, then l'étape est marquée « Échec », et le bandeau d'erreur nomme l'étape, le code de sortie et au plus 20 lignes d'erreur ; le Passage affiché ailleurs ne change pas.
- Given la barre de progression, when les étapes avancent, then `aria-valuenow` suit le nombre d'étapes terminées, et la région `status` n'annonce que les changements d'étape, la fin et l'échec.
- Given le bouton « Passer en Mode repli », when le Pilote clique, then le serveur bascule sur la copie du Passage de repli pour tous les écrans ; « Revenir au Mode réel » ramène au dernier Passage réel ; jamais de bascule automatique.

Contrat d'intention (extraits) : le lancement en Mode repli est refusé (409) avec un motif visible ; une seule Chaîne à la fois ; en cas d'échec le bandeau (role `alert`) donne l'étape (ou « hors d'une étape »), le code et les lignes d'erreur (« aucun message » s'il n'y en a pas) ; l'en-tête garde le Passage affiché.

Note d'environnement : l'application est démarrée en Mode réel (sans variable de repli) sur un dépôt sans données de Journal ni Passage publié : lancer la Chaîne échoue donc rapidement (c'est le cas d'échec de la story à vérifier). La Chaîne ne peut pas aboutir ici.

## Critères à parcourir
- C1 : `/chaine` en Mode réel : 10 étapes toutes « En attente », compteur « 0 / 10 », barre de progression avec `aria-valuenow` à 0 ; le bouton de lancement et le bouton « Passer en Mode repli » sont utilisables ; l'en-tête n'a pas de bouton « Lancer la Chaîne » sur cette page.
- C2 : cliquer sur le bouton de lancement démarre la Chaîne ; elle échoue ici ; l'écran montre l'échec : un bandeau d'erreur (role `alert`) qui nomme l'étape (ou « hors d'une étape »), le code de sortie et les lignes d'erreur (au plus 20), avec la précision qu'aucun rapport n'a été publié.
- C3 : après l'échec, quitter la page (aller sur `/`) puis revenir sur `/chaine` : l'état de la Chaîne (échec, bandeau d'erreur) est restitué tel quel.
- C4 : le bouton « Passer en Mode repli » bascule : la pastille de l'en-tête devient « Mode repli » avec le bandeau de repli, sans recharger la page ; la carte (`/`) montre alors le Passage de repli ; « Revenir au Mode réel » ramène la pastille « Mode réel ». Aucune bascule n'a lieu sans clic.
- C5 : en Mode repli, le bouton de lancement est bloqué : `aria-disabled="true"`, avec un motif visible relié par `aria-describedby` ; cliquer dessus ne lance aucune Chaîne.
