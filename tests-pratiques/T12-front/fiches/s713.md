# Story 7.13 : Socle web FastAPI et cadre commun

En tant qu'auteur, je veux que `usine ui` démarre un serveur FastAPI local qui sert le cadre commun des sept écrans, pour que la démo ait une interface web qui ressemble au produit d'une vraie équipe.

Critères d'acceptation de la story (extraits d'epics.md) :
- Given `usine ui`, when l'auteur le lance, then uvicorn sert l'application sur `127.0.0.1` seulement, et les sept URL d'écran répondent par une page HTML statique.
- Given n'importe quelle page, when elle se charge hors réseau, then polices, CSS et script viennent tous du serveur local, et aucune requête ne sort.
- Given le cadre commun, when on l'inspecte, then il porte l'en-tête (pastille « Passage publié » lue dans le manifeste, pastille de mode toujours visible, bouton « Lancer la Chaîne » absent de `/chaine`), la navigation latérale (`aria-current="page"`), le lien d'évitement, un seul `<h1>`, `<html lang="fr">` et un titre de page « {Écran} · Usine de migration ».
- Given `USINE_MODE_REPLI=1` au démarrage, when une page s'affiche, then la pastille « Mode repli » et le bandeau de repli sont visibles ; sans la variable, le mode est réel, et aucune bascule n'est jamais automatique.

Les sept URL : `/` (Carte météo), `/entites/ENT-A` (Détail d'une Entité), `/chaine` (Lancement de la Chaîne), `/agent` (Agent), `/avant-apres` (Avant / après), `/pseudonymisation` (Pseudonymisation), `/outillage` (Ce qu'il faut pour le faire en vrai).

## Critères à parcourir
- C1 : les sept URL répondent par une page ; chacune a le titre d'onglet « {Écran} · Usine de migration » (titre = nom de l'écran) et un seul titre de niveau 1.
- C2 : le cadre porte l'en-tête avec la pastille « Passage publié » (avec une date) et la pastille de mode toujours visible ; le bouton « Lancer la Chaîne » est présent dans l'en-tête de toutes les pages sauf `/chaine` ; la navigation latérale marque l'écran courant (`aria-current="page"`).
- C3 : le serveur est lancé en Mode repli : la pastille « Mode repli » et le bandeau de repli sont visibles sur chaque page visitée.
- C4 : le lien d'évitement est le premier élément atteint par Tab, il devient visible au focus et, activé avec Entrée, amène au contenu principal (le titre de l'écran).
- C5 : aucune requête ne sort vers un autre hôte que 127.0.0.1 (liste des requêtes réseau).
