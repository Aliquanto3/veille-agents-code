Observation 8. Skills have overtaken MCP as the most widely adopted extensibility standard in the corpus. Nine of the 11 systems implement SKILL.md bundles (all except Aider and Mini-SWE-Agent), compared with 8 of 11 for MCP. The two were tied in April, and Pi broke the tie by explicitly supporting skills but not MCP. Three second-order developments show that this layer is maturing. First, deferred loading is now the near-universal strategy, used by 8 of the 9 adopters. Second, conditional activation (paths in Claude Code, PathTrigger in OpenHands, requires in OpenClaw) brings just-in-time (JIT) context engineering into the extensibility layer. Third, a supply chain has emerged: four systems have hosted registries, Hermes has trust tiers and quarantine, and OpenClaw verifies provenance. The first skills written by agents have appeared at the same time, through Hermes's self-improving loop and Gemini CLI's extraction inbox.

Deferred loading as the dominant pattern. Eight of the nine adopters now load only skill metadata at startup and fetch the full body when it is needed. This mirrors Claude Code's deferred tool loading (Section 8.3). The systems fetch the body in different ways:
- a dedicated tool (SkillTool, ActivateSkill, skill, or invoke_skill in OpenHands);
- $-mentions plus detection of implicit invocation (Codex);
- a three-tier disclosure chain (Hermes);
- the ordinary read tool pointed at an XML index, the most minimal approach (Pi).

In April, OpenHands loaded skills eagerly. It switched to progressive disclosure with the V1 SDK. That leaves OpenClaw as the only system that loads skills eagerly. To compensate, it checks each skill's eligibility first, so ineligible skills never reach the prompt.

Gating and conditional activation. Of all the variations, conditional activation is the most interesting architecturally. OpenClaw skills declare runtime requirements (binaries on PATH, environment variables, OS family), and the system filters them at load time. On a machine without kubectl, "how to use kubectl" never enters the prompt. In Claude Code, the paths frontmatter field activates a skill when the model touches matching files through the Read, Edit, or Write tools. OpenHands now does the same thing with PathTrigger rules, which are injected when a file is touched. Both approaches connect skills to the JIT context philosophy of [19]. This is a structural advance over MCP, which handles every connected server the same way whether or not its tools matter for the current task.
