Observation 8. Skills have overtaken MCP as the most widely adopted extensibility standard in the corpus. Nine of the 11 systems implement SKILL.md bundles (only Aider and Mini-SWE-Agent do not), compared with 8 of 11 for MCP. Pi broke the April tie by explicitly supporting skills and not MCP. Three second-order developments show the layer maturing. Deferred loading is now nearly universal (8 of the 9 adopters). Conditional activation (Claude Code's paths, OpenHands's PathTrigger, OpenClaw's requires) brings just-in-time (JIT) context engineering into the extensibility layer. A supply chain has also emerged: hosted registries in four systems, trust tiers and quarantine in Hermes, and provenance verification in OpenClaw. Alongside it, the first agent-authored skills have appeared, in Hermes's self-improving loop and Gemini CLI's extraction inbox.

Deferred loading as the dominant pattern. Like Claude Code's deferred tool loading (Section 8.3), eight of the nine adopters now load only skill metadata up front and fetch skill bodies on demand. The mechanism varies. Some use a dedicated tool (SkillTool, ActivateSkill, skill, or OpenHands's invoke_skill). Codex detects $-mentions and implicit invocations, and Hermes uses a three-tier disclosure chain. Pi takes the most minimal approach: the model uses the ordinary read tool on an XML index. OpenHands loaded skills eagerly in April but moved to progressive disclosure with the V1 SDK. OpenClaw is now the only eager loader. It makes up for this with eligibility checks, so ineligible skills never reach the prompt.

Gating and conditional activation. Conditional activation is the most architecturally interesting variation. OpenClaw skills declare runtime requirements (binaries on PATH, environment variables, OS family) and are filtered at load time, so a "how to use kubectl" skill does not pollute the prompt on a machine without kubectl. Claude Code's paths frontmatter activates a skill when the model touches matching files through the Read, Edit, or Write tools. OpenHands now implements the same idea as PathTrigger rules, which are injected when a file is touched. Both approaches tie skills to the JIT context philosophy of [19]. This is a structural advance over MCP, which treats every connected server the same way, whether or not its tools are relevant to the current task.
