Observation 8. Skills have overtaken MCP as the corpus's most-adopted extensibility standard: 9/11 systems implement SKILL.md bundles (only Aider and Mini-SWE-Agent abstain) versus 8/11 for MCP, the tie of April broken by Pi's explicit skills-yes-MCP-no position. Three second-order developments mark the layer's maturation: deferred loading is now the near-universal strategy (8 of 9 adopters); conditional activation (Claude Code paths, OpenHands PathTrigger, OpenClaw requires) pushes JIT context engineering into the extensibility layer; and a supply chain has emerged—hosted registries in four systems, trust tiers and quarantine in Hermes, provenance verification in OpenClaw—together with the first agent-authored skills (Hermes's self-improving loop, Gemini CLI's extraction inbox).

Deferred loading as the dominant pattern. Echoing Claude Code's deferred tool loading (Section 8.3), eight of the nine adopters now load only skill metadata eagerly and fetch bodies on demand, via a dedicated tool (SkillTool, ActivateSkill, skill, OpenHands's invoke_skill), via $-mention and implicit-invocation detection (Codex), via a three-tier disclosure chain (Hermes), or, most minimally, via the ordinary read tool against an XML index (Pi). OpenHands, an eager outlier in April, moved to progressive disclosure with the V1 SDK; OpenClaw remains the one eager loader, compensating with eligibility gating so ineligible skills never reach the prompt.

Gating and conditional activation. The most architecturally interesting variation is conditional activation. OpenClaw's skills declare runtime requirements (binaries on PATH, environment variables, OS family) and are filtered at load time, preventing "how to use kubectl" from polluting the prompt on a machine without it. Claude Code's paths frontmatter activates a skill when the model touches matching files (via the Read, Edit, or Write tools), and OpenHands now implements the same idea as PathTrigger rules injected on file-touch—marrying skills to the JIT context philosophy of [19]. This is a structural advance over MCP, which treats every connected server symmetrically regardless of whether its tools are relevant to the current task.
